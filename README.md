# Automatic-Systematic-Review



The Automatic Systematic Review project will be a web application that uses AI to help researchers with developing their systematic reviews. The target audience is any researcher but the focus will be towards doctors. The main goal is automation and to minimize tedious steps as much as possible, such as suggestions for database search terms,  uploading of titles/authors/abstracts, screening papers based on specified criteria, and parsing and data extraction from full papers. Simultaneously the goal is not to detract from the scientific process and to be cognizant of the PICO framework.



This will be a website with an interface where users can login. The user interface should be clean and easy to understand, and the research steps should be built with seamlessness in mind. There will be an option for subscription payment but will be free initially.
